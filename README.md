# Devina Engineering Library

Personal engineering library for **Devina Azaria**.

This repository catalogs reusable technical patterns, starter kits, and project foundations that can be reused for research, experiments, competitions, school projects, and future engineering work.

## Working principle

**DevinaAzaria = Laboratory & Reusable Knowledge**  
**KERSAA = Institutional Adoption & Production**

A project should not end when the project ends. Useful patterns should be extracted into reusable engineering capital.

Flow:

```
Learn / Build
    ↓
Reusable pattern
    ↓
Starter kit
    ↓
Adopt in a real project
    ↓
Operational evidence
    ↓
Improve the reusable pattern
```

## Reuse rule

Before starting a new technical project:

1. Search this library and DevinaAzaria repositories for an existing pattern.
2. Reuse the closest working foundation.
3. Change domain logic, data schema, and UI as needed.
4. Never copy secrets, credentials, personal data, or production identifiers.
5. If the new project produces a generally useful pattern, extract it back into the library.

This library is intentionally separate from production systems. KERSAA may adopt patterns from here, but production-specific data and credentials remain in their own governed systems.
